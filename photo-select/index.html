手机照片与视频

一根线，存到电脑。

  1. 用支持数据传输的 USB 线连接安卓手机，开启「开发者选项 → USB 调试」，并在手机上允许这台电脑。
  2. 打开「安卓相册同步」，检测设备并扫描相册，选择文件类型、拍摄时间和相册。
  3. 确认电脑保存位置后开始同步。扫描显示旋转等待指示，传输显示数量与百分比，可随时停止；成功后自动预览。
同步范围与已有数据

发行包内置 ADB，无需另装工具。读取手机上已下载的相册原文件，不包含云端未下载的照片或私密相册。日期包含起止当天，优先使用拍摄时间，缺失时使用相册收录或文件修改时间。

再次同步跳过记录中仍存在的电脑副本，保留电脑上的编辑；源文件变化时另存版本。中断后可重新同步，未完成的单个文件从头传输。视频不参与照片标星或清理。

旧编号相册目录会自动迁移为可读名称，并保留同步和恢复记录。应用隐藏滚动条，滚轮、触控板与键盘滚动仍可使用。

开始使用

装好，就能选片。

  1. 下载并打开 DMG，将「照片快选」拖入 Applications。
  2. 从应用程序目录打开「照片快选」。
  3. 选择照片文件夹，开始浏览、标星与整理。
首次打开与版本说明

当前为 Apple Silicon 测试版，尚未完成 Apple Developer ID 签名与公证。如果系统阻止首次启动，请确认文件来自本站，再参考 Apple 官方说明，在系统提供的“隐私与安全性 → 仍要打开”入口自行确认。Intel Mac 暂不支持。

最低系统目标为 macOS 14，已在当前 Apple Silicon Mac 上完成验证，尚未覆盖所有系统版本。星级写入 JPG、RAW 与 XMP；像素蛋糕对外部星级的识别仍需实际导入确认。

后台随应用启动和退出，关闭窗口时会等待已提交的文件操作完成。旧网页版本的删除记录独立保留，需要在旧版本恢复。查看发行说明 · 下载 SHA-256 校验文件
